# Json

Um arquivo JSON (JavaScript Object Notation) é um formato de armazenamento e troca de dados que usa texto simples para representar estruturas de dados como objetos, listas e valores primitivos.

ex:

```json
{
  "name": "Ernesto",
  "email": "e@gmail.com",
  "age": 23,
  "isDeveloper": true
}
```
